# Akdağ ERP - Güncelleme Deposu

Bu depo, Akdağ ERP Android uygulamasının uygulama-içi güncelleme kontrolü için kullanılır.
`version.json` dosyası, uygulamanın açılışında kontrol edilir; yeni bir sürüm yayınlandığında
buradaki bilgiler otomatik olarak okunur ve kullanıcıya güncelleme teklif edilir.
